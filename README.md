# 小小宇宙 · Galaxy Explorer

一个面向儿童与亲子场景的可交互 3D 宇宙探索器。当前版本的探索路径：**本星系群 → 银河系 → 恒星系统 → 太阳系 → 行星 / 月球**。

## 在线预览

GitHub Pages：<https://cl1107.github.io/sol-gpt/>

- 程序化生成银河系旋臂、银河核心与深空背景
- 鼠标 / 触控拖拽旋转、滚轮缩放
- 银河系圆盘上的 8 个可点击恒星系统入口（太阳、半人马座 α、天狼星、波江座 ε、织女星、TRAPPIST-1、参宿四、Kepler-186）

- 地球与月球
- 土星环

- 行星快捷导航
- “找到地球”引导流程
- “我们在哪里？”尺度引导：地球 → 太阳系 → 银河系
- 搜索星系、附近恒星系统、八大行星、太阳、月球与人马座 A* 黑洞

## 技术方案

为了让 MVP 尽快形成稳定、可分享的预览，本项目采用零构建静态方案：

- Three.js ES Modules
- OrbitControls
- 原生 JavaScript / HTML / CSS
- 程序化星系粒子，不依赖大体积贴图或模型
- GitHub Pages + GitHub Actions

这种方式没有 Node 依赖安装步骤，Pages 直接部署仓库静态文件。后续内容规模扩大时，可以平滑迁移到 Vue 3 + TypeScript，并把当前天体数据和场景管理拆为独立模块。

## 本地运行

由于使用 ES Modules，请通过任意静态 HTTP Server 访问，例如：

```bash
python3 -m http.server 4173
```

然后打开 <http://localhost:4173>。

## 操作

- 拖动：旋转场景
- 滚轮 / 双指：缩放
- 点击天体：查看知识卡并靠近
- 顶部面包屑：在 本星系群 / 银河系 / 恒星系统 / 太阳系 之间返回
- 搜索：输入“天狼星”“TRAPPIST-1”“黑洞”等直接前往
